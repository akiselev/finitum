# Finitum

Finitum turns mathematical discretization requirements and local executable kernels into
concrete global operators. It owns meshes, prepared elements, basis and quadrature data,
degree-of-freedom maps, restrictions, constraints, assembly levels, scatter/gather, and
transfer operators.

The repository intentionally starts clean. None of the former scalar-P1
`sinbad-operator-runtime` implementation or its compatibility surfaces are carried forward.
